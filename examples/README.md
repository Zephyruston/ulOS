# example

这个目录包含了 ulOS 的使用示例代码。

## 作用

- **critical_section.c**: 临界区使用的示例
- **event.c**: 事件机制使用的示例
- **priority_inversion.c**: 优先级反转问题及解决方案的示例
- **queue.c**: 消息队列使用的示例
- **semaphore.c**: 信号量使用的示例
- **timer.c**: 定时器使用的示例
- **ulOS_example.h**: 示例代码的公共头文件

这些示例代码展示了 ulOS 各种功能的正确使用方法，帮助开发者快速理解和掌握 ulOS 的特性。
